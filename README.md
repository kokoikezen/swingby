# 스윙바이 시뮬레이터

태양계 중력장에서 우주선의 궤적을 **N-body 수치적분**으로 실시간 계산하는 웹 기반 시뮬레이터입니다.
행성 근접 통과(스윙바이) 시 운동 에너지가 어떻게 주고받아지는지 직접 실험할 수 있습니다.

별도의 빌드·서버 없이 `index.html`을 브라우저로 열면 실행됩니다.

---

## 물리 모델

| 항목 | 내용 |
|---|---|
| 적분기 | 4차 Runge–Kutta (RK4) |
| 상호작용 | 태양 + 8개 행성(수성~해왕성) 전체 상호 중력, 우주선은 질량 0 시험 입자 |
| 시간 간격 | 적응형 — 근접 시 자동으로 촘촘하게 (τ ≤ 0.04 d, 선형 여유 0.03, 최대 1일/스텝) |
| 소프트닝 | ε² = 10⁻¹⁶ AU² (특이점 완화용 최소값, 실질 영향 없음) |
| 단위 | 내부 계산은 AU · 태양질량 · 일, 표시는 km/s / AU 변환 |
| 이벤트 | 행성 SOI(중력권) 진입·이탈 감지, 진출입 속도 차로 스윙바이 Δv 산출 |
| 충돌 | 행성 반경 × 1.02 이내 접근 시 파괴 처리 |

행성 초기 위치는 원궤도 근사(반장축 a, 공전각 배치)이며, 이후는 순수 중력에만 의해 움직입니다.

## 사용법

### 발사
1. **출발 행성** 선택
2. **목표 초과속도 v∞**(0.2–15 km/s): 행성 중력권을 벗어난 뒤의 잉여 속도입니다.
   실제 발사속도는 `√(v∞² + 2μ/r)` 로 자동 보정됩니다.
3. **방향**: 행성 공전방향 기준 ±180°. `+°`는 앞쪽(왼쪽), `−°`는 뒤쪽입니다.
4. **🚀 발사** 클릭 — 또는 캔버스에서 행성을 클릭한 뒤 드래그로 방향·세기를 정해 발사
   (드래그 거리 ≈ v∞, 14 km/s/AU 스케일)
5. **스윙바이 자동 재시도**: 스윙바이 없이 임무가 끝나면(충돌·이탈, 또는 **10년 경과**) 같은
   v∞에서 발사각을 ±10°씩 바꿔가며 최대 18회까지 자동으로 다시 발사합니다
   (누적 스윙바이 ≥ 1회 보장 목적). 수동 발사·프리셋·초기화를 하면 자동 재시도가 취소됩니다.

발사 전 **예측 궤적**(흰 점선)이 실시간으로 그려집니다. 탄소색 구간은 해당 행성의
SOI 안을 통과하는 구간이고, 끝에 깃발이 붙습니다.

### 카메라
- 드래그: 화면 이동 / 휠: 확대·축소
- **우주선 카메라 추적**: 체크 시 시야가 우주선을 따라갑니다
- Space: 재생/일시정지 · Esc: 예측 취소

### 미션 프리셋
- **지구 → 화성 전이**: 호만 전이 궤도 + 위상각 자동 계산 (비행 약 259일)
- **보이저 2호 대탐사**: 지구 발사(v∞ 9.3 km/s) 후 목성 → 토성 → 천왕성 → 해왕성을
  순서대로 통과하는 그랜드 투어. 외행성 4곳의 위상각을 수치 탐색으로 배치해
  연쇄 스윙바이가 실제로 일어나도록 구성했습니다 (누적 약 +7 km/s, 해왕성 통과 약 19.6년)
- **금성 스윙바이 · 가속/감속**: 같은 v∞, 같은 꺾임각이라도 행성 **앞/뒤** 어느 쪽을
  지나느냐에 따라 에너지가 얻어지거나 잃는다는 것을 비교 실험할 수 있습니다

## 파일 구조

```
index.html        레이아웃·UI 마크업
style.css         다크 스페이스 테마
js/constants.js   물리 상수, 행성 정의, 포맷 유틸
js/physics.js     RK4 엔진(NBodyEngine), 적응형 dt
js/sim.js         시뮬레이션 상태, 발사/프리셋, SOI 이벤트, 궤적 예측
js/renderer.js    Canvas 2D 렌더링(카메라, 별, 궤도, 예측선)
js/ui.js          입력 처리, 프레임 루프, 텔레메트리·로그
js/main.js        부트스트랩
```

```
PASS | planet count (수성~해왕성)
PASS | earth period ~365d        (1년 오차 0.011°)
PASS | earth radius stable       (에너지 보존)
PASS | gain flyby encounter      enc=1
PASS | gain flyby gains energy   +1.41 km/s   (이론 +1.56)
PASS | loss flyby encounter      enc=1
PASS | loss flyby loses energy   −5.80 km/s   (이론 −5.78)
PASS | hohmann reaches mars SOI  t≈250일, 최근접 106만 km
PASS | voyager grand tour        목성→토성→천왕성→해왕성 연쇄 스윙바이
                                 (+6.35/+0.63/+0.15/−0.08, 누적 +7.04 km/s)
PASS | predict returns path      예측선 12년 지원(외행성 포함)
```

- 가속/감속 이론값: Δv∥ = v∞·[cos(θ±δ) − cos θ], θ=45°, δ=59.8° (v∞=6 km/s, 금성)
- 발사 방향 보상: 지구 중심 쌍곡선 탈출 시 속도 방향이 δ/2 만큼 꺾이므로
  `angleDeg + asin(1/e)/2` 로 사전 회전해 목표 방향과 일치시킴
